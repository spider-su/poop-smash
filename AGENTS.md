# Development guidance

- Keep this project independent from Rescue Team and its game-specific content.
- Target Godot 4.7.2 stable / GDScript and Android portrait screens.
- Run headless import, the rules test, and a scene boot before pushing.
- Do not introduce network permissions, tracking, ads, or accounts in the prototype.
- Prefer short, instantly responsive touchscreen interactions over complex menus.
- Keep main and develop as the only long-lived branches.
