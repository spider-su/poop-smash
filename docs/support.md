## Frequently asked questions
**Offline?** Yes. The current version runs without internet access.

**Ads or in-app purchases?** Neither is included in the current version.

**Reset data?** Android Settings → Apps → Poop Smash → Storage → Clear storage. This clears local preferences and scores.

**Permissions?** Vibration is used only for optional haptic feedback. The game does not request internet permission.

**Sound and vibration?** Toggle both in the game menu.
